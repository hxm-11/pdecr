## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

Answer each gate before research and re-check after design:

- **MVP Scope Discipline**: Does the plan stay inside the V1 loop of historical
  retrieval, AI draft generation, modular display, and basic export? If it adds
  formal approval flow, complex permissions, Outlook notifications, or automatic
  SuperOPL synchronization, move that work to post-V1 scope or document a
  constitutional violation.
- **Source-Grounded AI Output**: How will every generated conclusion retain a
  source case or source file reference? What is shown when evidence is
  insufficient?
- **Unified Historical Metadata**: Which code paths preserve `case_id`, `DC No`,
  `MCR No`, `change_type`, `product_no`, `part_no`, `customer_project`, and
  `source_file`?
- **Modular Result Contract**: How will the result expose Basic Info, Change
  Description, Reason for Change, Impact Analysis, Implementation Plan, and
  Approval / Sign-off?
- **Minimal Existing-Structure Change**: Which existing FastAPI, React, TanStack,
  Tailwind, and project modules are reused? Any broad refactor or new framework
  must be justified in Complexity Tracking.
- **Demo-Ready, Non-Production V1**: How will the feature remain demonstrable,
  trial-ready, and clearly non-production?

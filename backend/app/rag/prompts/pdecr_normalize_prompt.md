# PD-ECR 字段归一化（可选 LLM 辅助）

大多数归一化由 `normalizer.py` 用规则完成（字段别名、日期格式、多值拆分、
稳定 case_id）。当规则无法处理复杂表述时，可用本 prompt 让 LLM 辅助归一，
但**不得引入原文中不存在的信息**。

## 归一化目标

1. **字段名归一**：以下不同写法都归一到 `dc_no`
   - `DC No`、`PD-ECR No`、`PDECR No`、`Design Change Request No`
2. **多值字段统一为字符串数组**：`customer_project`、`affected_product_no`、
   `component_no`。用分号/逗号/换行拆分，逐项去空格与引号，去重保序。
3. **日期统一为 `YYYY-MM-DD`**。识别 `2024/9/3`、`2024年9月3日`、`20240903` 等。
4. **空值统一**：标量空 -> `null`；列表空 -> `[]`；剔除 `N/A`、`-`、`none` 等占位。
5. **不改写业务模块正文**，只做去噪（去页眉页脚、去乱码），保留原意。

## 输出

返回与抽取阶段相同的结构（metadata + 各业务模块），仅做上述规整。
若某字段无法可靠归一，保持原值或置空，绝不臆造。
